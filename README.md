# 工时随手记 (标准版)

为零时工、兼职及不固定工时群体提供极简、高效的记工时工具。解决手工记账难保存、工时核算易出错、缺乏结算依据的痛点，让每一分辛劳都有据可查。

## 主要功能
- **打卡记录**：实时显示今日已工作的总时长，一键“下班打卡”。
- **项目管理**：支持多项目、多雇主管理，自定义项目颜色和时薪。
- **历史记录**：按日期分组展示，支持左滑删除和详情编辑。
- **统计分析**：汇总本周/本月的总工时和预估收入，展示工时趋势图和项目分布。

## 技术栈
- 微信原生开发框架 (WXML, WXSS, JS)
- 本地存储持久化 (wx.storage)
